## What is included v2

- **Vision Inspection** — camera-based defect detection for high-speed lines.
- **Robotics Cell** — a pre-integrated pick, place and palletize workstation.
- **Edge Gateway** — protocol translation and buffering between plant and cloud.

## Positioning

| Product | Category | Designed for |
| --- | --- | --- |
| Vision Inspection | Quality | Inline surface and dimensional checks |
| Robotics Cell | Automation | Repetitive handling and end-of-line packing |
| Edge Gateway | Connectivity | Legacy machines without native OPC UA |

## Typical rollout

1. Assess the target line and collect the existing signal list.
2. Install the product in a shadow mode next to the running process.
3. Validate against a reference batch for at least one full shift.
4. Switch to active mode and hand over the operator dashboards.
