# Uso Avançado

Esta página testa um grupo de nav aninhado (`Guides`), que deve ser renderizado como
uma subseção dentro da página "Guides" na visualização de detalhes da documentação.

## Configuração personalizada

Você pode substituir `docs_dir` no `mkdocs.yml` para apontar para qualquer pasta
relativa ao próprio arquivo `mkdocs.yml`.
