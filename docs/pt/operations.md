# Operações

Tarefas de rotina para manter a documentação do Produto de Teste:

- Verifique se a pasta `en` sempre existe como idioma de fallback.
- Mantenha os caminhos do `nav:` relativos ao `docs_dir`, não à pasta de idioma.
- Execute a busca novamente após enviar novos arquivos markdown (o cache expira em 5 minutos).
