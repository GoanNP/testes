# Erweiterte Nutzung

Diese Seite testet eine verschachtelte Nav-Gruppe (`Guides`), die als Unterabschnitt
innerhalb der Seite "Guides" in der Dokumentationsdetailansicht dargestellt werden
sollte.

## Benutzerdefinierte Konfiguration

Du kannst `docs_dir` in `mkdocs.yml` überschreiben, um auf einen beliebigen Ordner
relativ zur `mkdocs.yml`-Datei selbst zu verweisen.
